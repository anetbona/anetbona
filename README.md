# Hi, I'm Aneta 👋

AI Product Builder and Product Manager. I take products from discovery through prototype to launch, build them myself with Lovable and Claude Code, and check what users actually do with them in PostHog.

7+ years in UX/Product at Samsung R&D, since 2025 focused on AI/LLM product design (currently: a data annotation tool for LLM projects). I trained as an architect at Warsaw University of Technology, then moved into UX with a postgrad at SWPS. Pro bono I work with the K.I.D.S. Foundation — I led its 10-person volunteer UX team for three years, and now build AI automations that help the foundation with grant writing.

Stack I reach for: React/TypeScript, Supabase, Tailwind, PostHog. I ship MVPs with Replit, Lovable and Claude Code (spec-driven development), integrate LLM APIs, run my own MCP server and deploy on Vercel.
